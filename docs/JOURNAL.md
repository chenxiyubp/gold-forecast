# 金绪1.2.0：数据初筛、预测留档与消息事件

这次不更改区间算法，不宣称准确率提升。新增的记录用于积累真正提前产生的预测，后续检验其效果。无需服务器或新账号。

## 使用

覆盖安装 GoldSense-1.2.0.apk，打开“分析”。原区间卡片下方增加“数据质量与前瞻验证”和“消息事件观察”。联网获取历史数据时自动留档，无需另行点击；点击“导出预测与资讯档案”保存CSV。

要进入提前预测统计，请在交易日日盘后北京时间16:00—19:45打开应用并成功刷新日线。仅当最新基准日就是当天、获取发生在16:00后、记录产生于夜盘前，才标记为可前瞻检验。其他时候仍保存为补记，不把事后记录算成成功预测。休市期间按旧基准日产生的记录会被保守排除。

## 数据质量

- 显示无效原始行数量，按已有校验拒绝非法日期、非正价格、不合理开高低收关系。
- 高低价相对前收偏离超过20%时标为待核验，保留原值，不自动纠正。这是工程初筛阈值，不是交易规则或认定数据错误的依据。
- 最近135条日线存在上述异常、或相应日期存在被拒绝的原始行时，暂停显示新预测范围和新留档。较早异常仍展示，历史评估可能受影响。
- 与上次缓存对照，记录同一日OHLC修订。尚未实现独立第二来源逐笔核实，因此页面明确显示“结构初筛”。

## 留档内容与评分

同一模型版本和基准日仅保存第一次记录；后续不会用更好的范围覆盖它。包含创建时间、来源获取时间、原上下界、中心、ATR、简单基准、输入指纹，以及当时已看到的近期资讯标识。指纹只是定位输入差异，不是完整行情快照或密码学证明；当地记录也不具备防人为篡改保证。

下一条有效日线在其日期16:00之后成功获取，才记录实际高低、是否覆盖及基准覆盖情况。无完整交易日历，所以目标是“下一条有效完成日线”；不能保证源接口缺失交易日时仍对应严格的下一交易日。找不到原基准行或结果出现极端异常，不直接评分。

评分后来源再修订时，保留第一次结果并标记修订；输入历史发生变化或结果待核验的记录不计入当前统计。页面同时展示样本数与命中数，不给小样本包装成胜率。最多保留200份预测，淘汰最早记录；定期导出以留存更长历史。

## 新闻事件

保存最多500条新闻的原始标题、来源链接、上游发布时间/日期精度、手机首次看到时间及规则分类。区分“预期或观点”与“标题待核实”，不把命中关键词当事实核验。不同日期的同标题可各自保留；同日同标题合并，不同标题报道同一事件目前仍可能重复。

分类包括货币政策、经济数据、地缘事件、央行黄金和交易所公告；能否采到某事件仍受现有新浪标题流及相关性过滤限制。最近首次看到的重要事件候选在应用内提示“原区间可能失效”，没有按新闻直接上调/下调预测价格，也没有根据时间接近断言因果。

成功采集相隔超过15分钟时记录一段“可能漏采”空档，最多200段。该阈值只描述观测间隔，不表示期间一定存在遗漏新闻。首次安装之前无法建立空档记录。

## 存储与通知

记录随原有缓存保存在手机本地。卸载或“清除本地数据”会移除全部档案，清除前请导出。CSV每行包含记录类型、ISO时间和完整JSON内容，可供后续程序分析。最多另保留200条来源修订记录。存储满时会显示保存失败提示。

本版仍在前台采集，锁屏、关闭应用期间可能漏采；没有新增后台任务或手机通知栏推送。消息观察目前是应用内提示。

## 验证

52项单元/回归测试通过，其中9项新增测试验证首次记录不重写、提前/补记区分、收盘后评分、修订排除、异常数据、资讯去重、采集空档、新闻时间集合和导出。手机尺寸浏览器测试验证留档持久化、导出调用、资讯保存、清除及页面布局。原生导出文件选择器和真实安卓设备仍待实测。
