# 金绪 1.3.0 · 精密仪表版

本版将选定的「精密仪表」设计实现为安卓应用界面，采用石墨灰、琥珀色、细分隔线和大字号价格。行情、资讯、分析、设置四个页面统一更新。

## 新的展示方式

- 首页价格标尺根据报价和实验性预测范围自动缩放；指针表示当前显示报价，矩形带表示区间，二者含义不同。
- 同屏展示 ATR14 和历史全日覆盖率；覆盖率是历史区间覆盖统计，不是未来上涨概率或交易胜率。
- 事件时间轴显示实际保存的资讯与预测留档，没有数据时显示空状态。
- 保留数据时间、休市/过期提示、来源状态、预测留档、数据校验、缓存和导出功能。

## 安装

安装 GoldSense-1.3.0.apk，要求 Android 8.0 或以上，并使用较新的 Android System WebView。沿用本地原签名和应用包名；使用同一签名的旧版可直接覆盖安装，不要先卸载，以免删除本地记录。

无需申请服务器或数据账号。数据获取仍依赖公开来源，自动刷新仅在应用前台进行；本版没有新增后台通知。
