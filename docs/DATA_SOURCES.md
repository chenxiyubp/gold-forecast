# 数据源与限制

核验日期：2026年10月6日。以下均为公开网页使用的数据来源，无需填写账号或密钥。服务由第三方提供，本项目无法保证长期可用性、固定延迟或永久免费。

| 用途 | 来源与路径 | 使用方式 |
|---|---|---|
| 国内黄金分时 | 上金所 `/graph/quotations?instid=Au99.99` | HTTPS GET；保留合约和源更新时间，过滤空值、零值和未来分时槽位 |
| 历史日线 | 上金所 `/graph/Dailyhq` | HTTPS POST，合约为 Au99.99；校验OHLC并保存最近800个有效交易日 |
| 黄金新闻 | 新浪财经 `/nmetal/` | 提取近七日相关标题、日期和原文链接；只标注日期精度，不伪造具体发布时间 |
| 备用宏观新闻 | 新浪滚动资讯 `/api/roll/get` | 贵金属页失败时使用；筛选黄金、美元指数、美联储、利率等标题 |

参考：[上海黄金交易所](https://www.sge.com.cn/)、[新浪财经贵金属](https://finance.sina.com.cn/nmetal/)、[AKShare 上金所数据说明](https://github.com/akfamily/akshare/blob/main/docs/data/spot/spot.md)。仅参考公开数据格式与接口路径；应用不依赖 AKShare Python 库。

## 关于“实时”

应用在前台自动获取上游最新可用数据，并立即在本机重新计算。上金所网站含延时行情；本应用不声称拥有交易所授权的逐笔实时推送。休市或分时无有效数据时，显示最近日线收盘并明确标识。

数据源刷新成功不代表数据时间更新。取得旧数据不会改写它的源日期；自动检查时间另行显示。报价高低、前收、变化率均来自同一合约，未把国际金价换算值冒充国内报价。

## 新闻范围

仅展示标题、来源、时间/日期和原文链接，不抓取整篇新闻。新闻情绪是标题措辞分析，不代表全文的真实含义，也不构成事件对价格的因果预测。同一事件可能有多篇报道；当前按标题去重，尚未实现跨标题事件聚类。

两条新闻获取方式均来自新浪，备用路径不等于独立供应商。公开网页结构可能变化，变化后需更新应用解析逻辑。

## 网络与隐私

- 仅声明联网及网络状态权限，无后台定位、通讯录、相册、短信权限。
- 数据请求只允许固定的上金所与新浪 HTTPS 域名；保留系统证书及主机名验证。
- 无账户、无广告SDK、无应用遥测；数据服务方仍会收到普通网络请求及IP地址。
- 手动输入标题在手机本地分析，不上传。
- 历史记录存储在应用本机空间。导出由安卓文件选择器让用户选择位置；不申请广泛存储权限。
- 在外部浏览器打开新闻时，将遵循新闻网站自身的访问及隐私规则。
