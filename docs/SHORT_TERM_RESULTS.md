# 金绪 1.1.0：短线分析可行性与使用说明

交付日期：2026-10-07。审查与历史评估于2026-10-06完成。

## 结论

用户提供的 short-term-stock-picker-main.zip 可以部分复用，但不能直接变成黄金次日预测器。本版已经复用均线逻辑，另外实现下一交易日价格范围估计，并加入历史滚动验证。适合观察波动尺度；目前范围较宽，不适合把上下界当成精确买卖点。

## 压缩包审查

包内有一份 SKILL.md、一个 scripts/pick_stocks.py，以及 README 和 MIT LICENSE。Skill 是操作说明，不是模型权重。其说明中的个人电脑路径及运行指令仅作为待审查内容，没有按它安装环境或执行选股脚本。

| 内容 | 处理 |
|---|---|
| MA5/MA10/MA20及多头排列 | 改写为手机本地计算，保留原作者许可；增加空头和交错状态 |
| 股票涨停、市值、ST、股票换手率 | 不适用于当前黄金数据，未移植 |
| 量比 | 当前接口只有开高低收，未制造成交量数据 |
| 主力净流入 | 文档提及，代码未实现，不能复用 |
| 次日区间预测及回测 | 压缩包中没有，由本项目新增 |

另外发现原脚本把工作日当交易日、静默跳过网络异常、输出路径写死，以及文档与成交量过滤逻辑不一致等问题。没有沿用它的综合评分作为预测概率。

## 新功能在哪里

覆盖安装 GoldSense-1.1.0.apk，打开“分析”，顶部为“下一交易日范围估计”。无需新增服务器或账号。

显示内容包括：基准日期、估计上下界、5/10/20日均线排列、近期波动ATR14、历史全日覆盖率、平均区间宽度、简单基准对照。点击“如何理解这个区间”查看口径。

模型以基准收盘为中心，用近120日最大偏离与波动的关系估计半宽。预测对象为基准日之后一个交易日的全日价格范围，不是第二天收盘目标价；均线标签只描述历史，不代表模型在预测涨跌方向。

## 历史验证结果

采用800条有效日线，先用当时已知数据生成范围，再检查下一条日线，未随机打乱日期。参数在观察结果前固定，没有根据结果挑选最优参数。评估期间：2025-09-16至2026-09-30，共252次。

| 指标 | 新增波动区间方法 | 简单历史波幅基准 |
|---|---:|---:|
| 全日高低同时被覆盖 | 225/252，89.3% | 218/252，86.5% |
| 平均区间全宽/前收 | 8.6% | 7.5% |
| 宽度与超界综合损失，越低越好 | 0.1302 | 0.1486 |

最近60次覆盖53次，88.3%；最后100次覆盖91次，91.0%。这些仍是同一数据集上的滚动历史回放，不是独立实盘收益或涨跌胜率。新方法覆盖更多、综合损失较低，同时范围也更宽，不能只用89.3%宣传“预测准确率”。

独立 Python 程序重新从每个历史前缀计算252份区间，与应用JavaScript结果逐一一致。43项单元/回归测试通过；手机尺寸浏览器测试覆盖区间显示、样本不足、缓存异常提示与清除数据。此前同一数据客户端真实联网成功，获得2375条原始日线及17条主来源新闻。

## 时点和实际限制

- 当日日线仅在北京时间16:00后重新获取成功才参与预测，防止上午缓存被当成收盘结果；否则使用此前日线。16:00是保守时间门槛，源接口没有最终确认标志。
- 显示“该基准日之后的下一交易日”，没有用周一至周五猜节假日。目标时段可能已经开始，必须看基准日期，不能机械理解为日历上的明天。
- 基准距今超过3天提示休市或滞后，超过10天暂停生成范围；没有新日线时保持原估计。
- 未使用交易所完整日历独立检查是否缺失某个交易日；上游历史数据也可能被修订。这些会影响历史评估。
- 未纳入重大新闻、海外价格、汇率、交易成本和滑点。当前只估计价格波动范围，不发买卖指令。
- 没有安卓真机连接，安装、系统WebView兼容及手机网络仍需设备实测。后台通知尚未在本次开发范围内。

详细公式、参考资料与复用依据见工程 docs/SHORT_TERM_METHOD.md；原压缩包文件留存在 docs/third-party/short-term-stock-picker，APK内包含第三方许可。
