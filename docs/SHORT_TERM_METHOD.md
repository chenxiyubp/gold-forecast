# 短线功能：预先确定的方法

2026-10-06，在查看回测结果之前固定以下方法和参数。仅做 Au99.99 下一交易日的全日高低范围估计，不做买卖指令或点价承诺，不按回测结果搜索最优参数。

## 用户提供代码的适用范围

short-term-stock-picker-main.zip 只有 README、SKILL、LICENSE 和 scripts/pick_stocks.py 四个文件。SKILL 是 A 股筛选操作说明，不是训练模型。读取它是审查参考材料，不执行其硬编码的个人环境路径。MIT 许可允许改造，保留作者和许可。

借用 analyze_stock 的 MA5/MA10/MA20 计算及多头排列判断，将其改写为手机本地 JavaScript；增加对称空头/交错状态作为历史描述。黄金不存在该脚本所用的流通市值、ST、A 股涨停股池、股票换手率筛选。现有黄金数据只有 OHLC，不能伪造成交量或资金流。

代码缺陷包括：用周一至周五代替交易日，忽略节假日；吞掉接口异常导致样本遗漏；近三日比较首尾实际只有两个收益间隔；文档说量比须大于1但代码没有该过滤；主力净流入未实现；输出路径写死。项目没有区间预测、训练、回测或误差评估，不能直接迁移成黄金预测器。

## 新增区间模型（本项目独立实现）

- 用 Wilder ATR14 估计近期价格波动。TR=max(高-低, |高-前收|, |低-前收|)，最早14个真实波幅均值初始化，后续按 (13×前ATR+当前TR)/14 更新。
- 历史每一天 i，计算全日最大偏离 e_i=max(|高_i-前收|, |低_i-前收|)，再除以前一天已知 ATR。不得除以当天 ATR。
- 取最近120个上述偏离的90%经验分位数（nearest rank，ceil(0.9×120)），乘最新ATR，得到区间半宽。中心为最新收盘，区间下界至少0.01元。显示下界向下、上界向上取整到分。
- 90%只是选用的历史分位参数，不是下一天有90%概率落在区间。市场序列存在相关性和分布变化，不适用简单独立同分布的保证。相关方法限制参考 [Gibbs & Candès, 2021](https://arxiv.org/abs/2106.00170)。本功能不是该论文 ACI 算法的实现。
- 对照基准：最近120日 e_i/前收的90%经验分位数乘当前收盘。无ATR自适应；其余中心、目标与计分口径相同。
- 均线排列独立展示，不据其多空标签偏移区间或生成上涨概率。新闻标题没有历史时间一致的样本，不用于预测模型。

## 验证设计

至少135条有效、严格升序、不重复的日线才能生成第一份区间。使用现有最多800条日线，以先预测后见到下一条真实OHLC的方式滚动评估，最近最多252个交易日；另展示最近60日与最终100日结果。历史数据可能经来源修订，不等于真实发布时点存档，不把它称为已完成实盘验证。

统计全日高低同时被覆盖的比例、收盘落入率、平均区间宽度/前收及宽度加超界惩罚的区间损失。区间损失为宽度+20×max(下界-真实最低,0)+20×max(真实最高-上界,0)，再除以前收；越低越好。必须与简单基准对照，宽区间不能仅靠覆盖率宣传准确。

界面显示实际历史覆盖率，不给涨跌胜率。当最近60日样本少于30条，或全日覆盖率低于80%，显示评估不足/近期覆盖偏低。波动为零、输入非法或样本不足时拒绝生成价格区间。

## 时点与休市

数据源没有明确的“最终日线”标志，未来日期记录一律排除；当日日线只在北京时间16:00后再次成功取得才纳入，否则从上一日及之前数据建模。选择16:00是对上金所15:30日盘结束预留缓冲，不代表交易所最终数据确认标记。上午缓存不会在下午自动视为已收盘。该可用时点规则在接入界面时细化，未改变区间算法或回测参数。页面标明基准日期和“该日之后的下一交易日”，不使用简单工作日算法猜节假日。

模型估计可能对应当前正在交易的时段，不能一律称为“明天”。距离基准日超过3个自然日提示休市或滞后，超过10天暂不生成区间；这是展示保护条件，不是交易所休市日历。即使上游刷新失败，历史回测仍可看，但必须注明缓存/失败；没有新的日线时不重复生成看似新的预测。
