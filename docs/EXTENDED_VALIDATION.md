# 黄金区间算法：数据验证报告

验证日期：2026-10-07。算法参数固定，不按本次结果优化。

## 结论

算法有可解释的波动统计依据，但没有证据证明能精确预测第二天价格或可靠指导短线买卖。它以最新收盘为中心，不预测涨跌方向；90%历史分位参数不等于明日覆盖概率。

## 算法依据

ATR14描述近期波动，结合过去120日“次日最高/最低相对前收最大偏离÷预测前ATR”的90%经验分位数，生成对称范围。合理性来自波动的时变尺度与历史经验分布，不来自原股票Skill的选股评分。均线只作历史背景。

[Fidelity ATR说明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)支持其波动衡量用途。时间序列分布变化会影响区间覆盖，[Gibbs与Candès论文](https://arxiv.org/abs/2106.00170)讨论了这一问题；本程序并未实现论文的ACI算法，也不能借用其理论保证。

## 数据和流程

使用先前真实联网取得的上金所日线响应，共2375行。日期/正价格/高低关系校验后保留2358行，排除17行，重复0行。响应SHA256：`7a134f1cb574e4b229c3ca5ad28d0df3252893e6fe325e8fc61dc85c79aad8e1`。

首135条作预热，随后进行2223次逐日回放，期间2017-07-20至2026-09-30。每次只向算法提供截至基准日的最近最多800条记录，然后才读下一条真实高低价。相同预测引擎和参数用于全区间及基准对比。

这是扩大历史回放，不是新增实盘样本或全新独立数据源。原先最近252次评估包含在本次结果内，不能把两次检验当作独立证据。未用完整交易日历确认缺失日期，部分预测目标可能是下一条可用日线。

最差60次发生于2019-05-09至2019-08-01；全部历史最长连续5次未覆盖。

## 优势有多可靠

用宽度加超界惩罚的自定义损失衡量（越低越好）：(上界−下界+20×下穿幅度+20×上穿幅度)/前收。这是比较工具，不是收益、胜率，也不是有理论保证的全日90%区间评分。

全部历史：方法0.0768，基准0.0803。最近252次：方法0.1302，基准0.1486。

用长度20的连续时间块做2000次循环块重采样（固定种子20261007），保留部分相邻依赖，估计差值的近似95%区间：

- 全历史方法减基准损失：-0.00774 至 -0.00039。该重采样设定下支持较小的平均改善。
- 最近252次方法减基准损失：-0.04647 至 0.00386，跨过0，不能确认近期稳定优于基准。
- 最近252次覆盖率重采样区间：83.73% 至 94.05%。

这些近似区间依赖块长度、现有样本与分布假设，不是下一天覆盖概率，也不覆盖未来制度变化或数据源错误。没有做块长度搜索。

## 测试与复现

既有43项测试包括ATR数值、135日门槛、未来数据不影响过去预测、当前未完成日线过滤、缓存时点、异常数据拒判等。另有独立Python检查，逐一复算此前252个历史区间，与手机JavaScript一致。计算一致证明代码实现相符，不证明金融预测有效。

新增 tests/extended-validation.cjs 直接调用交付应用同一预测引擎；完整逐日结果见《短线扩展验证数据.json》。工程docs保存原始响应 validation-history-20261006.json 以便复现：

```text
node tests/extended-validation.cjs docs/validation-history-20261006.json extended-results.json
```

## 当前可接受用途

可用于观察次日可能波动尺度和提示超出历史常态；仍属实验功能。不能宣称精确预测、明日90%概率、可盈利交易策略。要提升可信度，需要核对源数据异常，并在真实运行中提前保存每天区间，等下一交易日结束再评分，持续积累未参与设计的新样本。本次没有修改算法参数或安装包。
