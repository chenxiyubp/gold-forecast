# 1.0.2 新闻主入口修复

2026-10-06 用户反馈资讯页持续启用备用来源。复现发现：旧请求标识包含 Android，新浪贵金属页面返回 HTTP 302，跳转到 api.cj.sina.cn 的移动入口。应用按设计不自动跟随跨域跳转，所以进入备用分支。旧错误提示没有区分移动跳转和网站故障。

修复：请求标识使用明确的应用名称 GoldSentAnalysis/1.0.2，不声明 Android 平台，以取得原网站 HTML 版。没有放开域名限制、没有禁用证书验证、没有增加服务器或账号。

验证：使用与 APK 同一份 Java DataClient 实际请求，主页面 HTTP 200，UTF-8 解码无替代字符，解析到 17 条近七日标题；news() 返回 fallback=false、source=新浪财经 · 贵金属。行情与 2375 行历史响应也正常。数量为当次快照，不是固定保证。

使用：覆盖安装 GoldSense-1.0.2.apk，打开资讯页后点右上角刷新。已有旧缓存可能暂时保留原提示，成功取得新数据后提示消失；无需清空缓存。若某次主入口确实失败，仍会自动使用备用入口。该修复已在电脑端同源客户端验证，尚未在用户手机上复验。
